## 微信协议API，稳定高效的微信接入能力
- 提供消息收发、好友管理、群管理、标签管理等基础能力
- 无需安装额外依赖，无需hook，使用安全稳定
- 业务系统通过标准API进行对接，可同时登录数百账号，并且与手机端、PC端同时在线，既实现自动化操作，又不影响正常业务使用
- 提供完善的代理与验证支持，保障使用过程中的稳定性

## 核心功能
### 登录
- 获取登录二维码/检测登录结果；支持登录过程中的验证；支持快捷登录和当前登录状态检查
### 消息收发
- 消息发送：支持文本/语音/图片/视频/文件/链接/小程序/视频号/名片等各种消息类型的发送；支持消息撤回
- 消息接收：通过回调将接收到的消息推送到业务系统；多媒体消息，可以通过API下载
### 通讯录管理
- 好友管理：获取微信和企微好友列表和详情；搜索/添加/通过/删除微信和企微好友；管理好友标签和备注
- 群管理：建群/退群/解散群聊；添加成员/邀请成员/同意成员进群；管理群管理员/群公告/群备注/群成员等；获取群成员详情
- 联系人变更：好友或群信息发生变更，通过回调将变更消息推送到业务系统
### 代理
- 支持本地代理/自有代理/平台代理等多种代理模式

## 使用优势
### 两种接入方式
1. 对接SaaS服务，可以直接在平台上执行登录操作、查看登录状态，然后通过API对接实现其他业务操作
2. 私有化部署，系统和数据完全独立，您的业务安全有保障；业务系统通过API完成登录和其他业务对接

以上两种接入方式，您都不需要负责部署和维护底层系统，只需专注于上层业务开发
